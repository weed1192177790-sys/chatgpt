# Supplier Search

## Purpose
为具体采购需求寻找真实、匹配的生产厂家。

## Trigger
找厂家、推荐厂家、定制厂家、谁能做、国内哪家做得好。

## Workflow
1. 识别产品、材料、工艺、尺寸、数量、定制程度。
2. 判断应该寻找哪一类工厂，而不是只按产品名称搜索。
3. 优先查官网、企业主页、行业协会、工程案例、招投标、1688工厂信息。
4. 区分生产厂家与贸易商。
5. 核对主营业务是否真正匹配。
6. 核对定制能力、工程案例、出口能力、交期和产能线索。
7. 输出候选厂家，并说明适配原因与风险。

## Output
厂家名称 / 地区 / 主营 / 工厂属性 / 定制能力 / 适合采购内容 / 官网或联系方式 / 风险备注。
