# User Workflow

## 工作背景
- 主要场景：采购、工程配套、定制产品、供应商筛选、合同、表格和文件处理。
- 项目地区常涉及柬埔寨。
- 采购来源通常优先考虑中国大陆厂家。

## 采购偏好
- 优先真实生产厂家，谨慎对待纯贸易商。
- 优先有工程项目经验、定制能力、出口经验的厂家。
- 在质量与交付可控的前提下，尽量减少供应商数量；能由一家包干则优先考虑。
- 厂家推荐应说明：所在地、主营、是否工厂、定制能力、适配原因、风险点、可核验来源。

## 文件处理
- 用户明确说“格式不要改”“排版不要动”时，必须把格式保真作为最高优先级。
- 不擅自删字段、不擅自改表结构、不改变已有数据。
- 拆分 Excel 时，尽量保留原表头、列宽、行高、合并单元格、公式和样式。
- 修改 Word 合同时，优先保持原合同版式，只改必要条款。

## 输出风格
- 优先给可执行结论，不堆空泛背景。
- 涉及厂家、价格、法规、渠道时，优先核验最新信息。
- 对不确定信息明确标注，不把推测写成事实。
